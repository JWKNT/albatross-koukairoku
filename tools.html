English patch

Complete build

Converts a verified Japanese installation into the complete translated build. It includes the fully audited script, English word wrapping, horizontal presentation, localized menus and gallery graphics, an English-safe text size, and the macOS/CrossOver fullscreen fix.

  1. Download and extract the archive, whether this is a fresh install or an update.
  2. Run Install Albatross English Patch.command on macOS or the .bat launcher on Windows.
  3. Drag the folder containing 信天翁航海録.exe into the prompt. Launch the game normally when it finishes.

Verification and rollback
